# 사랑흐름 안내 영상 만들기 (클로드용 도구)

휴대폰 화면(412×732, 2배 선명)으로 저장소 화면을 띄워 자동으로 눌러 가며 찍고, 자막 · 누르는 곳 표시 · 앞뒤 사랑흐름 표지를 넣어 720×1280 MP4로 만든다. 자막 시간표(SRT)와 내레이션 대본(_대본.txt)도 같이 나온다.

- 화면: 이 저장소 파일을 그대로 씀(인터넷의 사이트가 아님).
- 서버가 필요한 화면: `server.js`가 실제 Apps Script 코드(.gs)를 가짜 시트 · 가짜 카카오로 돌림. `LF_REC_GS=경로` 로 서버 파일을 줌(서버 파일은 저장소에 없음 · 대표가 첨부).
- 실행: `node v_hanmadi.js` · `node v_draw.js` · `LF_REC_GS=/path/우리이야기_Code_v12_261011.gs node v_open.js` → `out/` 에 mp4 · srt · 대본.
- 필요한 것: Playwright(Chromium) · ffmpeg.
- 목소리: 대표 녹음 파일을 받아 줄마다 길이에 맞춰 단계별 기다림을 늘려 다시 찍은 뒤 섞음(다음 할 일).
